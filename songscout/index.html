For the person managing this library: add audio files you own or have permission to share to the music folder, then add each file to the TRACKS list near the bottom of this HTML file. Use a matching filename such as music/my-song.mp3. MP3 and M4A are good audio choices; an MP4 file will only play if it contains an audio format the browser supports. Keep filenames simple.

Offline tip: visitors must download files while online. To use the whole site with no internet, include the HTML and authorized audio files in a ZIP and download that ZIP before school.
